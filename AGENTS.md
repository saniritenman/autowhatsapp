# Project notes

AutoWhatsApp is independent of BottleTrack. Never modify BottleTrack resources for this project.

Never read, publish or commit `.env.local`, `bridge/.local/`, `.wa-session/`, `.wwebjs_auth/`, `.wwebjs_cache/`, or credential/session files. When collecting source for publishing, exclude these paths explicitly; a manual file traversal does not respect `.gitignore` automatically.

The active free mode uses FREE-PC.md and Start-Free.cmd. Do not create paid Render resources unless the user later approves a reviewed paid plan. Do not enable real WhatsApp sending without a user-approved test recipient and message.
